### A security claim is only as useful as the evidence behind it.

I'm **Bavly Wagyh**, a cybersecurity undergraduate in Cairo, Egypt. I investigate vulnerabilities, build security-focused tools, and care about the difference between a feature that looks convincing and one that can be independently tested.

My work spans **Web/API security**, **digital forensics**, **security systems engineering**, and **evidence-aware analysis**. I prefer clear threat models, reproducible findings, honest limitations, and useful interfaces.

### 01 — [Insider Lens](https://github.com/bavlybibo/Insider-Lens)
**Satellite evidence / NASA Space Apps Cairo 2026**

A working, publicly deployed wildfire-hotspot exploration project built with a three-person team. It compares **MODIS and VIIRS** observations with bounded region/time controls, source-separated evidence, and explicit handling of analytical limits.

[Live project](https://insider-lens.pages.dev) · [Source and technical notes](https://github.com/bavlybibo/Insider-Lens)

### 02 — CyberVault X
**Encryption / local security workflows**

A security-focused vault featuring **AES-GCM encryption**, password-derived key protection, audit records, encrypted backup workflows, and privacy-aware reporting. The project emphasizes safeguards and testable behavior over decorative security claims.

### 03 — GeoTrace Forensics X
**Digital forensics / evidence provenance**

A desktop investigation workflow for **EXIF and GPS metadata**, timeline reconstruction, SHA-256 integrity checks, chain-of-custody logging, geolocation analysis, and shareable case reports.

### 04 — Wireless Policy Manager
**Network segmentation / access policy**

A policy-oriented wireless management prototype covering **SSID/VLAN and role mapping**, isolation controls, audit trails, event review, and report exports.

<sub>Project descriptions reflect implemented prototypes and documented workflows; they are not claims of production deployment or certification.</sub>

## 03 / On the workbench

**Insider Eye — active development**

Developing a policy-aware insider-threat security platform that combines endpoint workflows, backend controls, analytics, and AI-assisted detection research. This is **ongoing engineering and research**, not a finished commercial product.

I am particularly interested in the contract between a model, the data it receives, the policy boundaries around that data, and the evidence needed to trust an alert.
